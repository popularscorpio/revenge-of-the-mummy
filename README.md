 Revenge of the Mummy

A platformer game I made in HTML and JavaScript.

The game takes place inside a pyramid where you have to collect relics while trying not to get caught by Anubis. There is lava, multiple endings and some horror elements. I am still working on it and adding new stuff when I get ideas.

 Features

* Platformer movement
* Ancient Egyptian theme
* Anubis stalker
* Lava
* Multiple endings
* Horror atmosphere
* GitHub Pages support

 Why I made this

I wanted to make something cool and learn coding at the same time. At first I had no idea what I was doing but somehow it turned into a game. It is not finished yet and there are probably bugs and wierd things but I will keep improving it.

Future plans

* Secret rooms
* Puzzles

 Controls

A / D = Move

W or Space = Jump
